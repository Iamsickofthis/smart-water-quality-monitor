# 💧 Smart Water Quality Monitor

A machine learning-based web application for analysing water quality datasets and classifying water samples as **Safe** or **Unsafe**.

The project provides an interactive dashboard where users can upload a CSV dataset containing water-quality parameters. The trained machine learning model analyses the uploaded records and generates predictions. The results are presented through a user-friendly dashboard with summary information, graphical visualizations, and a detailed dataset analysis table.

---

## 📌 Project Overview

Water quality monitoring is important for determining whether water is suitable for consumption and other applications. Traditional water-quality analysis can involve manual testing and laboratory procedures, which may require considerable time and resources.

The **Smart Water Quality Monitor** provides a software-based approach to water quality analysis using **Machine Learning and Data Analytics**.

The system accepts a water-quality dataset in CSV format and uses a previously trained machine learning model to classify individual records.

Each record is classified as:

- 🟢 **Safe**
- 🔴 **Unsafe**

The system also calculates the overall proportion of safe and unsafe samples and presents the result through an interactive web dashboard.

---

## 🎯 Objectives

The main objectives of the project are:

- To develop a web-based water quality monitoring system.
- To analyse water-quality datasets using Machine Learning.
- To classify water samples as Safe or Unsafe.
- To provide an easy-to-use dataset upload facility.
- To display prediction results in an understandable format.
- To visualize water-quality information using graphs.
- To provide a summary of safe and unsafe water samples.
- To reduce the effort required for preliminary water-quality analysis.
- To provide a foundation for future real-time water monitoring systems.
